Financial Fraud Detection System

A Machine Learning powered web application that analyzes real transaction patterns — spending amount, merchant category, location, and timing — to predict whether a transaction is Genuine or Fraudulent in real time.

Try a Prediction View Live Dashboard
Real Kaggle Dataset

Trained on 1.85M+ real, simulated credit card transactions from the Kaggle "Credit Card Transactions Fraud Detection" dataset — including merchant category, customer location, and demographic data.

Engineered Features

Raw data is transformed into meaningful signals: customer age, distance between customer & merchant, and the hour/day of the transaction — real feature engineering, not just raw columns.

4 Models Compared

Logistic Regression, Decision Tree, Random Forest, and XGBoost were trained and compared on Accuracy, Precision, Recall, and F1-Score — with class imbalance handled properly.
